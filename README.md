# HR Employee Analytics Dashboard 

An interactive **HR Analytics Dashboard** built using **Microsoft Power BI** to analyze employee data and generate meaningful HR insights.

## 🛠️ Tools Used

* Power BI
* Power Query
* DAX
* Data Visualization

## 📌 Dashboard Highlights

* Employee workforce overview
* Department-wise employee analysis
* Employee demographics
* HR performance insights
* Interactive charts and KPIs

## 🎯 Objective

To transform employee data into an interactive dashboard that helps understand workforce patterns and supports **data-driven HR decision-making**.
